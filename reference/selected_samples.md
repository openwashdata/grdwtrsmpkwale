# Samples of selected venues collected 3 weeks in a row

Samples of selected venues collected 3 weeks in a row

## Usage

``` r
selected_samples
```

## Format

A tibble with 24 rows and 69 variables

- code:

  Code of the sampling point: an abbreviation of the site name followed
  by the weekly sampling round (1 = 10 June, 2 = 18 June, 3 = 24 June
  2016).

- date:

  Date the sample was taken.

- conductivity:

  Conductivity of the sample in (µS/cm)

- T_avg:

  Average ambient temperature at the time of the sampling

- pH:

  Acidity/basicity of the sample using the pH value.
